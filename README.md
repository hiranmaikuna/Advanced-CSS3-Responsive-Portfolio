# 🌐 Advanced CSS3 & Responsive Portfolio

## 📌 Project Description

This project is a modern, professional and fully responsive personal portfolio website developed using **HTML5, CSS3 and JavaScript**.

The portfolio demonstrates advanced CSS3 concepts such as **CSS Grid, Flexbox, CSS Variables, responsive media queries and light/dark mode**. The website is designed using a mobile-first approach so that it works properly on mobile phones, tablets and desktop computers.
